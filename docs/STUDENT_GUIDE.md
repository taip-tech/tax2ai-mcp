# 수강생 안내: TAX2.AI 세무 법령 MCP 사용하기

AI(Claude)가 법제처 원문을 직접 찾아보고 근거 조문·결정례를 붙여 답하게 해 주는 무료 도구입니다.

## 1. 가장 쉬운 방법: Claude 웹·데스크톱
TAX2 계정(카카오 로그인)이 필요합니다. 없다면 https://www.tax2.ai 에서 먼저 가입하세요.

1. Claude 설정 → **커넥터** → **사용자 지정 커넥터 추가**
2. 이름 `TAX2.AI`, URL `https://mcp.tax2.ai/mcp` 입력 → 다음
3. 인증은 **"지금 로그인"**(기본값) 그대로 둡니다. OAuth 클라이언트는 화면이 자동으로 고른 값을 그대로 두고, 고를 수 없으면 **"자동으로 등록"**을 선택합니다.
4. **추가** → **연결**을 누르면 TAX2 로그인 창이 열립니다.
5. 카카오로 로그인 → "TAX2.AI 세무 법령 MCP 연결" 화면에서 **허용**
6. Claude로 돌아오면 연결 완료. 새 대화에서 커넥터를 켜고 질문합니다.

> 사용자 지정 커넥터는 Claude 요금제에 따라 개수 제한이 있을 수 있습니다.

## 2. Claude Code 사용자
```
/plugin marketplace add taip-tech/tax2ai-mcp
/plugin install tax2ai@tax2ai
```
설치 후 `/semu 질문` 으로 사용합니다. 깊은 검토는 `/semu deep 질문`.

## 4. 본인 법제처 키 (필수)
법령·결정례 조회에는 본인 키가 필요합니다. 공용 키는 제공하지 않습니다. 계산 도구는 키 없이 쓸 수 있습니다.

1. https://open.law.go.kr 가입 → **OPEN API 사용 신청**
2. 신청 정보의 **서버 도메인**에 `mcp.tax2.ai` 를 등록합니다. ← 꼭 필요합니다. 빠뜨리면 "OC 인증에 실패했습니다"가 나옵니다.
3. 승인되면 OC 값(가입 이메일의 @ 앞부분)을 확인합니다.
4. https://tax2.ai/mypage/office 의 **법제처 API 키** 칸에 OC를 넣고 저장합니다. 저장할 때 법제처에 실제로 확인하고, 커넥터 주소는 바꾸지 않아도 됩니다. 1분 안에 Claude·ChatGPT 등 연결된 곳 모두에 적용됩니다.
   - TAX2 회원이 아니면 커넥터 주소를 `https://mcp.tax2.ai/mcp?oc=본인OC` 로 넣으세요. 로그인 없이 법령·결정례·계산 도구를 쓸 수 있습니다. (사무소 설정·반 참여·학습 제출은 로그인 필요)
   - Claude Code 플러그인은 설치할 때(또는 플러그인 설정에서) OC 입력란에 넣어도 됩니다.

> 이미 다른 용도로 OC를 쓰고 있다면 기존 IP·도메인은 그대로 두고 `mcp.tax2.ai`만 추가하면 됩니다.
