# 제안요청서 (RFP)
## 세무사 실무용 법령·결정례 MCP 서버 「tax2ai-mcp」 구축

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.2 (2026-10-31) |
| 서비스 주소 | `https://mcp.tax2.ai/mcp` (TAX2.AI) |
| 발주 | TAIP Technologies |
| 사업 기간 | 착수 후 10주 (MVP 4주 + 고도화 6주) |
| 산출물 형태 | 오픈 표준 MCP 서버 (stdio / Streamable HTTP), 소스코드, 운영 문서, Claude Code 서브에이전트 묶음 |

---

### 1. 사업 개요

#### 1.1 배경
- 세무사 업무의 상당 시간이 **근거 확인**(조문 원문·시행 시점·위임 법령·결정례 탐색)에 쓰인다.
- 범용 생성형 AI는 조문 번호·사건번호를 그럴듯하게 지어내는 경우가 있어, 그대로 의견서에 쓰기 어렵다.
- 법제처 국가법령정보 공동활용 Open API는 법령·판례·해석례·행정규칙을 무료로 제공하지만, 세무 실무 흐름에 맞춘 가공 계층이 없다.

#### 1.2 목적
1. AI 어시스턴트(Claude, 기타 MCP 클라이언트)가 **법제처 원문을 직접 조회해 근거를 제시**하도록 한다.
2. 세무사의 반복 업무(조문 확인, 귀속연도별 적용 문언 확인, 경정청구 기한 계산, 인용 점검)를 도구화한다.
3. 사무소 내부 AI 워크플로(검토메모, 고객 답변, 경정청구 검토)의 공통 기반으로 쓴다.

#### 1.3 범위
| 포함 | 제외 |
|---|---|
| 법제처 DRF API 기반 법령·결정례·행정규칙·별표서식·법령용어 조회 | 홈택스 등 국세청 시스템 연동, 신고서 전자제출 |
| 세무 특화 가공(약칭, 시점 조회, 인용 점검, 쟁점 묶음) | 고객 개인정보·장부 원본 저장 |
| 결정적 계산(산출세액, 신고·경정청구·제척 기한) | 최종 세액 확정, 가산세 확정 |
| Claude Code 서브에이전트·프롬프트 워크플로 | 웹 UI (2차 사업) |

### 2. 현황 및 문제점

| 문제 | 영향 |
|---|---|
| 조문 번호·사건번호 오인용 | 의견서 신뢰도 하락, 재작업 |
| 사업연도별 적용 법령 혼동 (개정 경과규정) | 경정청구·조사 대응 오류 |
| 시행령·시행규칙 위임 추적 수작업 | 조사 시간 증가 |
| 결정례 검색 창구 분산 (법원·심판원·법제처) | 누락 위험 |
| 기한 계산 수작업 (휴일 순연, 성실신고 특례) | 기한 도과 위험 |

#### 3.2 비기능 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 정확성 | 모든 법령 응답에 법령명·조문·시행일을 함께 표기. 원문을 확인하지 못한 경우 명시적 오류코드 반환 |
| NFR-02 | 오류 투명성 | `KEY_MISSING / KEY_REJECTED / UPSTREAM_DOWN / BAD_PAYLOAD / NO_MATCH / BAD_INPUT` 구분, "결과 없음"과 "조회 실패" 혼동 금지 |
| NFR-03 | 성능 | 캐시 적중 시 100ms 이내, 미적중 단건 조회 p95 3초 이내 (업스트림 정상 시) |
| NFR-04 | 부하 보호 | 업스트림 동시 호출 상한(기본 4), 5xx 지수 백오프 재시도(3회), 타임아웃 10초 |
| NFR-05 | 응답 크기 | 기본 14,000자 단위 분할, `cursor`로 이어받기 |
| NFR-06 | 보안 | OC 키는 환경변수·헤더로만 주입, 로그 미출력. 외부 공개 시 토큰 또는 공개 모드 호출 제한, 브라우저 Origin 허용 목록, 요청 본문 1MB 제한 |
| NFR-07 | 개인정보 | 서버는 입력 원고를 저장하지 않음 (메모리 캐시는 법제처 응답만 보관) |
| NFR-08 | 이식성 | Node.js 20+, 외부 DB 불필요, 단일 프로세스 |
| NFR-09 | 유지보수 | 세율표·약칭 사전·자료원 필드 매핑을 데이터 파일로 분리, 개정 시 코드 로직 수정 불필요 |
| NFR-10 | 테스트 | 도메인 로직 단위 테스트 + 가짜 업스트림 기반 도구 통합 테스트, CI에서 자동 실행 |
| NFR-11 | 배포 | 고정 IP 서버 + 컨테이너 + TLS 리버스 프록시, 법제처에 서버 IP·도메인 등록 |

#### 3.3 데이터 출처
- 법제처 국가법령정보 공동활용 Open API (`https://www.law.go.kr/DRF/lawSearch.do`, `lawService.do`, `type=JSON`)
- 사용 target: `law`, `eflaw`, `thdCmp`, `oldAndNew`, `prec`, `detc`, `ttSpecialDecc`, `expc`, `admrul`, `licbyl`, `lstrm`
- 인증: 공동활용 사이트 가입 후 OPEN API 신청 → 승인된 **OC 값** + 호출 서버 IP/도메인 등록

                       ▼
          법제처 국가법령정보 DRF API

### 10. 면책
